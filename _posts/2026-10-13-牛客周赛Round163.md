## B小月的十六进制

***

十六进制转二进制：一位十六进制对应四位二进制

> eg.
> 
> 3 -> 0011
> 
> B -> 1011
> 
> B3 -> 1011 0011

x 被 $2^k$ 整除 -> x 二进制最低位的 1 的位数要大于等于k

代码如下

```cpp
void solve() {
    string s;
    int k;
    cin >> s >> k;

    auto Val = [&](char c) {
        if(isdigit(c)) {
            return c - '0';
        }
        return c - 'A' + 10;
    };

    int res = 0,cnt = 0;
    for(int i = s.size() - 1;i >= 0;i--) {
        int val = Val(s[i]);
        if(val) {
            res = cnt + __lg(val & -val);
            break;
        }
        cnt += 4;
    }
    
    cout << ((!res || res >= k) ? "YES" : "NO") << endl;
}
```

__lg：计算整数的以 2 为底的对数向下取整，返回数字的最高位 1 所在的索引

x & -x 结果保留 x 最低位的 1，其余全变 0

## C小月的对局

***

**穷举**

~~你是说我deepseek半天打开一看发现是穷举吗~~

代码如下

```cpp
void solve() {
    int n;
    cin >> n;
    vector<int> a(n),b(n);
    for(auto& x : a) cin >> x;
    for(auto& x : b) cin >> x;
    sort(b.begin(),b.end());

    do {
        bool res = true;
        for(int i = 0;i < n;i++) {
            if(gcd(a[i],b[i]) > 1) {
                res = false;
                break;
            }
        }
        if(res) {
            cout << "Bob" << endl;
            return;
        }
    } while(next_permutation(b.begin(),b.end()));
    cout << "Alice" << endl;
}
```

next_permutation ：按字典序生成下一个排列

sort + next_permutation : 枚举全排列

## D小月的地砖

***

妙妙小办法 : 像铺地砖一样把 1 一排一排连接着铺进去就好了，铺满换行

代码如下

```cpp
void solve() {
    int n,m;
    cin >> n >> m;
    vector<int> a(n);
    for(auto& x : a) cin >> x;

    vector<string> s(n,string(m,'0'));
    int cnt = 0;
    for(int i = 0;i < n;i++) {
        for(int j = 0;j < a[i];j++) {
            s[i][cnt] = '1';
            cnt++;
            if(cnt == m) cnt = 0;
        }
    }
    for(auto row : s) {
        cout << row << endl;
    }
}
```
